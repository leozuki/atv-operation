## 🌟 CÁC PHÂN HỆ QUẢN TRỊ THEO ĐÚNG NGHIỆP VỤ ATTIVO

### 1. 🚢 Quản Lý Logistics, Đặt Hàng Quốc Tế & Nhập Kho 2 Miền
- **Nhà sản xuất đa dạng**: Theo dõi độc lập từng hãng (Precor, Ziva, Merrithew, Skelcore, KOMPAN, Vita, Paviflex...).
- **Đơn hàng ghép nhiều dự án (Consolidated PO)**: 1 mã PO/Container chứa thiết bị của nhiều dự án khác nhau (Ví dụ: PO `ULS-AT2625` chứa hàng cho Grab + Vietcombank bù + S3.45 Clubhouse Fulton).
- **Phân luồng 2 kho**:
  - **Kho Đông Anh (Hà Nội - DA)**
  - **Kho Bình Dương (BD)**
- **Phương thức vận chuyển**: Đi tàu biển (**Sea Freight**) vs Đi máy bay (**Air Freight**).
- **Kiểm soát PO Date & ETA**: Dự kiến ngày tàu về, ngày làm thủ tục hải quan, ngày cập kho và xuất lắp ráp.
- **Giám sát sai lệch & thiếu hụt**:
  - ⚠️ **Hãng giao thiếu (Vendor Shortage)**: Nhà máy xuất thiếu linh kiện (như vụ Ziva thiếu 4 bộ rack).
  - ⚠️ **Order thiếu (Internal Shortage)**: Nội bộ lên đơn sót cần đặt bù (như lô dumbbell Vietcombank đặt bù).
  - ✅ **Đúng & Đủ (Pass)**: Khớp 100% packing list.

## 🚀 HƯỚNG DẪN CHẠY DỰ ÁN

Hệ thống được xây dựng trên nền tảng **React 19 + Vite + Tailwind CSS v4 + Lucide Icons**:

```bash
# 1. Cài đặt thư viện (nếu chưa cài)
npm install

# 2. Cấu hình token HubSpot (chỉ dùng phía dev server, không vào bundle)
cp .env.example .env.local   # rồi điền HUBSPOT_ACCESS_TOKEN

# 3. Chạy test (Vitest)
npm test

# 4. Khởi chạy môi trường phát triển (Dev Server)
npm run dev

# Ứng dụng chạy tại: http://localhost:5188/
```

- Dữ liệu được tự động lưu trữ vào `localStorage` của trình duyệt. Bạn có thể thêm đơn hàng PO, thêm dự án, chỉnh sửa lịch kỹ thuật, cập nhật tiến độ thiết kế.
- Khi cần phục hồi lại bộ dữ liệu ban đầu từ tài liệu thực tế của Attivo, chỉ cần bấm nút **"Khôi Phục Dữ Liệu Gốc"** ở chân trang.
